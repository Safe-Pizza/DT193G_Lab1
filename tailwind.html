Tailwind CSS

Tailwind CSS är ett CSS-ramverk av typen utility-first där man använder små färdiga klasser direkt i HTML-koden för att skapa önskad design. Jämfört med traditionella ramverk fokuserar Tailwind CSS på att ge större flexibilitet och mer skräddarsydd design där utvecklaren bygger egna komponenter.

Utvärdering av Tailwind CSS

Inlärning

Från början kändes det som att Tailwind hade en brant inlärningskurva. Det fanns så mycket olika klasser att lära sig bara för att göra det mest basic som att sätta padding, margin, centrera osv. Det var lätt att förstå vad de olika klasserna gjorde tack vare grundläggande kunskap i CSS men för en nybörjare måste det vara svårt att sätta sig in i och svårt att komma igång att designa. Jag installerade Tailwind IntelliSense på slutet vilket underlättade med förslag så man inte hela tiden behövde sitta med näsan i dokumentationen eller cheat sheets.

Färdiga komponenter vs flexibilitet

Tailwind kändes som att allt fokus låg på flexibilitet och verkar inte ha mycket färdiga komponenter. Det krävdes ganska mycket klasser för att tex styla en knapp eller formulär vilket gjorde att det gick åt ganska mycket tid för att få till ett helt formulär. Så min upplevelse är att det är väldigt flexibelt vilket jag själv tycker är en stor fördel, speciellt eftersom jag tidigare bara skrivit egen CSS-kod, men med nackdelen att det då blir mer tidskrävande.

Designfrihet

Jag upplevde att Tailwind hade stor designfrihet. Det gick att på ett enkelt sätt anpassa färger, storlekar och avstånd. Då tailwind använder preflight som standard för att normalisera mellan webbläsare får man lite som en blank canvas att arbeta med vilket gör att man kan skapa unika designer. Dock krävs det såklart mycket klasser för detta vilket gör HTML-koden stökig och inte speciellt överskådlig.
