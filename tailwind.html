Vad är Tailwind CSS?

Tailwind CSS är ett utility-first CSS-ramverk som gör det enkelt att skapa anpassade användargränssnitt direkt i HTML. Istället för att skriva egna CSS-klasser, använder man färdiga klasser som representerar olika stilar och egenskaper.
