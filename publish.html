Vad är Cloudflare Pages?

Cloudfare Pages är en tjänst där man kan publicera webbplatser och webbapplikationer. Den har stöd för att publicera statiska webbplatser men har även stöd för dynamiska webbplatser/applikationer. Det går att koppla Cloudflare Pages till ett GitHub-repo och publicera webbplatsen automatiskt när man pushar ändringar till repot. Det går även att publicera manuellt via Cloudflare Pages webbgränssnitt.

Programmeringsspråk

Cloudflare stödjer flera ramverk och språk:

  • Språk
    • JavaScript
    • TypeScript
    • Python*
    • Rust*
    • Go*
  • Ramverk
    • React
    • Vue
    • Angular
    • Svelte
    • Next

Ovan är endast exempel på vad som stöds och det finns såklart fler alternativ. Vissa ramverk kräver Cloudflare Workers eller annan konfiguration för att fungera korrekt

* - Endast delvis stöd, kan användas i byggprocessen eller genom Cloudflare Workers eller med Webassembly.

Kostnad

Cloudflare Pages erbjuder en gratis nivå med begränsad resursanvändning som passar för hobby projekt eller personliga projekt. För mer avancerade funktioner och högre prestanda kan man uppgradera till en betald plan med listade priser från $20 till $250 per månad.

Publiceringsprocess på Cloudflare Pages

Jag valde att koppla Cloudflare till mig github-repo för denna uppgift. Det gör att när en push till main görs så kommer Cloudflare automatiskt uppdatera webbplatsen från senaste commit.

Eftersom jag valt att använda Vite som byggverktyg använde jag Cloudfares plugin med wrangler för att publicera. Med detta plugin kan man även testa den webbplatsen lokalt i Cloudeflare miljö.

Arbetssättet för publicering av denna webbplats:

  • Push till main-branch på Github
  • Cloudflare känner av ändringen
  • Cloudflare kör vites byggprocess med kommando npm run build
  • De färdiga filerna från Vites byggprocess läggs i mappen /dist
  • Cloudflare kör Wranglers deploy med kommando npx wrangler deploy som publicerar filerna från /dist
  • Webbplatsen har publicerats
