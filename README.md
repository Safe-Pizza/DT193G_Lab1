# Laboration 1, DT193G - Fullstack-utveckling med ramverk
Detta är en laboration i _Webbutveckingsprogrammet_ på Mittuniveristetet.

## Länk till webbplats
[Min webbplats](https://dt193g-lab1.hannaclindkvist.workers.dev/)

## Syfte
Syftet med laborationen är att lära sig och utvärdera CSS-ramverk för webbutveckling samt använda och utvärdera icke FTP-baserade publiceringsmetoder.

## Uppgifter
Uppgiften består av flera delar som framgår i listan nedan:
 * Använda och utvärdera 2 st CSS-ramverk,
 * Skapa 4 undersidor: startsida, publicering och för respektive ramverk,
 * Använda ramverken för styling av tabell och formulär.

## Lösning
För laborationen har jag valt att använda ramverken Bootstrap och Tailwind CSS. Projektet använder Vite som byggverktyg och webbplatsen är publicerad med Cloudflare Pages.

## Installation
1. Klona repot
    ```sh
    git clone https://github.com/safe-pizza/DT193G_Lab1.git
    ```

2. Gå in i projektmappen
    ```sh
    cd DT193G_Lab1
    ```

3. Installera
    ```sh
    npm install
    ```

4. Starta en lokal utvecklingsserver
    ```sh
    npm run dev
    ```
